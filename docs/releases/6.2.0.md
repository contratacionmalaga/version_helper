# version-helper 6.2.0

Actualización de mantenimiento respecto a **6.1.4**, publicada con Java 21. Renueva las dependencias y herramientas heredadas, actualiza GitHub Actions y sustituye el README por una guía completa de integración y uso. No introduce cambios en la API pública ni en el comportamiento de consulta del manifiesto.

Las versiones Maven se heredan de `jarios-parent:1.0.15`; no se introducen sobrescrituras locales. La actualización de `setup-java` afecta a CI, Quality, Dependency Check y Release Package.

Se mantienen Java 21, Maven 3.9.16, Maven Wrapper 3.3.4, JUnit Jupiter 6.1.3 y AssertJ 3.27.7. Se conservan los plugins Dependency 3.11.0, Enforcer 3.6.3, JAR 3.5.1, Javadoc 3.12.0, Release 3.3.1, Source 3.4.0, Antrun 3.2.0, Checkstyle Maven 3.6.0 y OWASP Dependency-Check 13.0.0. También se mantienen checkout v7.0.1, cache v6.1.0 y upload-artifact v7.0.1.

El parent también actualiza versiones gestionadas de otros componentes del ecosistema. Esas entradas no incorporan nuevas dependencias a version-helper ni implican que esta biblioteca utilice dichos componentes.

## Renovación de README.md

Se sustituye el README anterior por documentación estructurada y sincronizada con 6.2.0:

- Identificación del artefacto, requisitos y versiones de referencia.
- Integración Maven y configuración de acceso a GitHub Packages, incluido el parent.
- Ejemplo completo con imports, resultado tipado y manejo de excepciones.
- Tabla de los cinco estados de consulta y compatibilidad con la API histórica.
- Configuración de `App-Version` y `App-Name` en el manifiesto consumidor.
- Límites de resolución de clases, protocolos y empaquetados con JAR anidados.
- Documentación de `FinalDelProgramaHelper` y sus códigos de salida.
- Tabla de dependencias, ámbitos y responsabilidad del consumidor sobre logging.
- Comandos de compilación, pruebas y calidad para Windows, Linux y macOS.
- Descripción de los tres JAR generados y de la verificación del manifiesto.
- Workflows, activadores, credenciales y procedimiento real de publicación por tag.
- Resolución de problemas, documentación histórica y situación de la licencia.

Se aclara que `jarios-parent:1.0.15` todavía gestiona `version-helper:6.1.4`; los consumidores deben declarar 6.2.0 explícitamente hasta que su gestión de dependencias la incorpore.

## Publicación y mantenimiento

- El POM pasa a 6.2.0 y corrige el comentario obsoleto que identificaba las pruebas como JUnit 5.
- El workflow publica estas notas desde `docs/releases/6.2.0.md`, sustituyendo el texto genérico de release.
- El tag de publicación es `v6.2.0`, con verificación de coincidencia con el POM.
- Se publican el artefacto Maven y los JAR principal, de fuentes y de Javadoc.
- Antes de preparar esta versión se cerraron las PR obsoletas de Dependabot #14–#18 y se eliminaron sus ramas: sus cambios ya estaban cubiertos por el parent anterior.
